任务一 · 提示词工程师：让 AI 听懂需求

需求：① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停 ③ 圆点分页器可点 ④ 初始效果为 cube —— 生成 new Swiper('.mySwiper', {...}) 配置

硬性要求：至少迭代 2 轮提示词，保留每轮提示词与 AI 回答；亲自粘贴页面验证，用截图 + 一句话说明证明验证结果。

第 1 轮：我的提示词（说得笼统，AI 果然没听全）

我 → AI
帮我写一个 Swiper 配置：无缝循环，自动播放，间隔 3.2 秒，有圆点分页器，切换效果用 3D 立方体，类名是 .mySwiper。
AI 回答（第 1 轮）
new Swiper('.mySwiper', {
  loop: true,
  autoplay: { delay: 3200 },                        // 错误①：少了 disableOnInteraction:false，手动拖动后自动播放会停止
  pagination: { el: '.swiper-pagination' }          // 错误②：页面上真实的圆点元素不是这个类，而且没有 clickable:true，圆点不可点
})                                                  // 错误③：effect:'cube' 整个漏了，效果还是默认的 slide 平推

错在哪：AI 把"自动播放"理解成了最简写法；"圆点分页器"给了官方默认类名而不是我页面里真实存在的元素；"3D 立方体"直接被丢了。结论：需求不逐条列清楚，AI 一定漏。

第 2 轮：改进提示词（逐条编号 + 指出上一轮错误）

我 → AI（第二轮）
你上一轮漏了 3 处，重来，逐条对照我列的需求，一条都不能少：① 无缝循环（loop）② 自动翻页间隔 3200 毫秒，且用户手动拖动后自动播放不能停（disableOnInteraction:false）③ 圆点分页器用页面里真实存在的元素 .wre-pag，并且必须可以点击跳转（clickable:true）④ 初始切换效果必须是 cube 立方体。写完代码后，用注释标出每一条需求对应哪一行。
AI 回答（第 2 轮 · 修正版）
new Swiper('.mySwiper', {
  loop: true,                                        // 需求① 无缝循环
  autoplay: { delay: 3200, disableOnInteraction: false }, // 需求② 3.2秒自动翻页，手动后不停
  pagination: { el: '.wre-pag', clickable: true },   // 需求③ 圆点可点跳转
  effect: 'cube'                                     // 需求④ 初始效果为 3D 立方体
});

亲自验证：把修正版配置贴进本页演示台（下方就是真实运行结果）

验证结论（每项需求一句话）：
① 无缝循环 ✓ —— 最后一张继续往后翻，画面回到第一张，没有"到头回弹"。
② 自动翻页不停 ✓ —— 按住拖动一次松手后，约 3.2 秒又开始自动翻页（disableOnInteraction:false 生效）。
③ 圆点可点 ✓ —— 点击第 3 个圆点直接跳到 C919 那张（clickable:true 生效）。
④ cube 生效 ✓ —— 切换时可见 3D 立方体旋转（F12 查看 .wre_mySwiper 容器多了 swiper-cube 类）。
说明：截屏此演示台即可作为验证截图，也可自行粘贴到自己的页面复验。

答辩自查：第一版提示词漏的是「手动操作后自动播放不停止」这条——我只说了"自动播放"，没说不被用户打断；第二轮用"逐条编号 + 指出上轮错误 + 要求注释对应"才把需求钉死。

任务二 · creative 仿写：课堂没讲，AI 教你

为演示四新增第 7 个按钮「creative 电影胶片」，效果：上一张缩小左移带角度退场，下一张放大右移进场，像电影选片

过程：打开官方示例 swiper/demo/257-effect-creative.html，配合 AI 读懂 creativeEffect 的 transform 写法，再自定参数实现"电影胶片"效果。

关键对话：问 AI 官方示例的 transform 怎么读

我 → AI
官方示例 257 里 creativeEffect 的 prev/next 里写着 translate:[0,0,-320]、rotate:[0,0,-45] 这种数组，每个数是什么意思？百分号写法又是相对谁？
AI 回答（要点）
prev 描述「当前 slide 的上一张」在动画进行时变成什么样，next 描述「下一张」；translate 是 [x, y, z] 三个方向的位移，百分比相对 Swiper 容器自身的宽度/高度，z 是像素（负数往屏幕深处退）；rotate 是 [x,y,z] 三轴旋转角度，单位度；另外还可以配 scale、opacity、shadow。

动手：在 swiper-task.html 演示四新增第 7 个按钮（已完成，可点击验证）

<button data-fx="creative">creative 电影胶片（AI 自学·任务二）</button>

// 效果为 creative 时附加的自定义变换（写在 wre_buildCfg 里）
creativeEffect: {
  limitProgress: 2,
  shadowPerProgress: true,
  prev: { translate: ["-42%", 0, -260], rotate: [0, 0, -12], scale: 0.78, opacity: 0.55 }, // 上一张：左移42% + 推远 + 逆时针歪12度 + 缩小 + 变淡
  next: { translate: ["115%", 0, -60], scale: 1.18, opacity: 0.9 }                          // 下一张：停在右侧115% + 放大1.18倍 → 像更大的海报从右冲进来
}

用我自己的话写：prev / next 的 transform 各控制什么

prev 控制"上一张"翻页时的退场姿态：这里让它向左平移容器宽度的 42%、沿 Z 轴后退 260px（看起来变小变远）、再绕 Z 轴逆时针歪 12 度、缩到 0.78 倍、透明度降到 0.55——像上一张海报被随手甩到左边角落。
next 控制"下一张"的进场姿态：它一开始停在容器右侧 115% 宽度的地方（看不见），还放大到 1.18 倍；翻页时这张"更大"的新海报从右边冲进来占住 C 位——电影选片那种"下一张压过来"的感觉就出来了。

答辩追问预答：transform 里的百分号相对 Swiper 容器自身的宽度/高度（z 方向是像素）。要"让卡片转 20 度"，把 prev 的 rotate 第三项从 -12 改成 -20（rotate:[0,0,-20]）刷新即可看到倾斜加大。

② 课堂没讲过的能力：keyboard 键盘控制（关键对话）

我 → AI
课堂只讲了 loop / autoplay / pagination / navigation / effect，我想给演示四加键盘方向键翻页，但页面里有 4 个轮播，怎么保证按 ←/→ 只控制演示四、不影响页面滚动和其他轮播？
AI 回答
用 Swiper 的 keyboard 模块：
keyboard: { enabled: true, onlyInViewport: true }
enabled 开启键盘监听（监听 document 的 keydown，←/→ 触发 slidePrev/slideNext）；onlyInViewport:true 表示只有当这个轮播在可视区域内才响应按键——页面里的 4 个轮播不会同时被控制，滚到演示四附近按方向键才是它的。AI 第一次只给了 keyboard:true，四轮播一起翻页，后来改成对象写法并加了 onlyInViewport 才对。
答辩四连问预答：
1. 这段代码什么意思？—— keyboard 模块监听键盘事件，按 ←/→ 调 slidePrev/slideNext；onlyInViewport 限定只有演示四滚进视口才接收按键，防止一按方向键全页轮播齐动。
2. AI 第一次给的哪里不对、你改了什么？—— 第一次只给 keyboard:true，4 个轮播一起翻页；改成 keyboard:{enabled:true, onlyInViewport:true} 对象写法并限定视口。
3. 新参数的作用？—— enabled 是模块开关；onlyInViewport:true 是"轮播进入可视区域才响应键盘"，把键盘控制权交给当前看到的那一个。
4. 把 autoplay 的 delay 改成负数会怎样？—— 负数相当于 0：动画一结束立刻翻下一张，轮播变成几乎无停顿的"无缝连播"，每张内容根本看不清，autoplayTimeLeft 进度也失去意义；Swiper 不会报错，但这个参数已经没有实际意义了。
